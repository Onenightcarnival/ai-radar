# Anthropic 官方动态周报（2026-W47）

## 本期最重要的信号

本期已有日报中，最集中的信号是 agent 持续运行所需的工程条件变得更具体。11 月 12 日的 Managed Agents 自托管私测说明运行环境、凭据与会话记录可以如何部署；11 月 13 日的常驻 agent 指南则讨论事件唤醒、去重、记忆与审批。相比上一期强调记忆纠错和企业控制，本期进一步落到执行架构与部署选择。

业务入口也在扩展：制造业插件、会议测试版和创业团队 Claude Tag 实践，把任务放进业务记录、会议和 Slack 频道。它们共同强调连接现有工具与人员审核，但各自的可用范围和权限不同。本期缺少三天日报，以下判断仅代表已有材料，不能视为整周发布情况的完整描述。

## 常驻 agent 的关键是执行协调与可控部署

11 月 13 日的指南把常驻 agent 拆为事件收件箱、定时器、记忆、权限和发件箱：agent 多数时间休眠，被事件唤醒后执行任务，再把需要延续的信息写入持久存储。事件去重、单个收件箱只有一个活跃 worker，以及延迟审批，直接关系到任务是否重复执行、状态是否丢失和无人值守时如何获得授权。[常驻 agent 指南](https://claude.com/resources/articles/building-always-on-agents)

11 月 12 日，Managed Agents 自托管版本进入私测。企业可在自己的云环境或本地运行执行框架、沙箱、凭据管理和会话历史，并选择模型请求的发送位置；核心 API 与托管服务保持一致。部署评估可据此检查控制平面与沙箱隔离、凭据代理、网络白名单及会话审计，但不能把私测理解为已普遍开放。[自托管 Managed Agents](https://claude.com/resources/articles/self-hosted-claude-managed-agents)

上一期的记忆文章关注跨会话整理与纠错，本期增加了事件、并发执行和审批机制。两期材料合起来提示：记忆能否复用只是持续运行的一部分，团队还需明确谁触发任务、同一任务如何去重、何时暂停等待人工处理。这是对已有官方材料的归纳，并非效果验证结论。

## 业务协作向制造、会议和团队频道扩展

11 月 12 日的 Claude for Manufacturing 提供 17 项技能和四个连接器，连接 Autodesk Fusion、Infor、Microsoft 365 与 Oracle NetSuite，支持报价、质量报告、故障分析和供应商询价。Team 和 Enterprise 用户可安装；流程以人工审核为终点，结果可追溯到底层记录，不直接操作设备。值得关注的是业务资料如何进入任务以及审核如何落到具体记录。[制造业插件](https://claude.com/resources/articles/claude-for-manufacturing)

同日开始测试的 Claude Meetings 可作为可见参会者加入 Google Meet，回答问题、整理纪要和待办，并协作生成文档与白板。连接工具需要授权，管理员开关、外部参会者和资料可见范围影响实际使用；测试版暂不支持部分启用 ZDR、HIPAA-ready 或 CMEK 的组织。因此，会议入口的扩展仍需结合组织配置判断。[Claude Meetings](https://claude.com/resources/articles/claude-meetings)

Claude Tag 指南汇总八家创业公司的排障、生成 PR、知识查询、数据分析和周期报告实践，并提供频道、连接器和起始指令示例。代码修复仍由人员审核后合并。与上一期 Marketplace 采购入口和摩根大通受控部署相比，本期更多描述日常任务怎样进入协作过程，不能据案例数量推断整体采用率或生产率提升。[创业团队指南](https://claude.com/resources/articles/claude-tag-guide-for-startups)

## 模型选择贴近任务分工，安全评测要求更完整的证据

11 月 12 日的 J.Crew 案例中，团队用 Claude Code 开发穿搭顾问原型，线上用 Sonnet 5.5 处理造型对话、Haiku 5.5 处理快速任务，推荐素材来自品牌造型师作品。它展示了开发工具、线上模型和品牌资料的分工；日报没有提供可用于横向比较的收益指标。[J.Crew 案例](https://claude.com/resources/articles/j-crew-style-advisor-with-claude)

同日的 Opus 5.5 知识工作指南介绍研究、分析和文档等用法，并称其已成为 Pro、Max、Ultra 和 Team 的默认模型。指南结合速度、用量成本与任务复杂度讨论切换模型和调整推理强度。这里保留日报所载产品状态；性能案例来自官方测试与客户反馈，不能直接替代团队自身任务的验证。[知识工作指南](https://claude.com/resources/articles/using-claude-opus-5-5-as-your-daily-driver-for-knowledge-work)

11 月 13 日的安全评测文章强调先明确待衡量行为，用贴近真实使用的多轮情境测试，并以人工判断校验自动评分器；分析方法应预先确定，运行配置和不确定性应完整报告。拒答率不足以单独衡量安全，还要检查有害配合、正常请求的过度拒绝，以及分数差异的统计意义。相比上一期新模型与科研案例，本期提供了更具体的评测方法，适合用于审视能力与安全结论的证据质量。[安全评测方法](https://www.anthropic.com/research/building-strong-safety-evaluations)

已有日报没有记录 Economic Futures 新内容，也不足以支持新的就业、宏观生产率或政策趋势判断。
