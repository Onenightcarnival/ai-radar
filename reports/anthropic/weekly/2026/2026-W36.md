# Anthropic 官方动态周报（2026-W36）

## 本期最重要的信号

本期 Anthropic 的核心动作，是让 Claude 在更多工作入口中保留上下文并直接执行任务，同时把控制边界做得更明确。Claude 的记忆打通 chat 与 Cowork，Claude in Chrome 面向付费用户正式可用，Cowork 则增加与个人浏览器隔离的内置浏览器。三项更新共同指向一个更连续的 agent 体验：Claude 可以记住工作背景、进入网页环境并完成多步操作，而用户仍能查看和编辑记忆、选择授权范围，并在不同浏览器模式之间权衡便利与隔离。

研究与安全侧也在扩大“可验证、可外部检验”的范围。Anthropic 资助独立团队建立用户福祉评测，通过隐私保护工具向外部研究者开放聚合使用数据，并展示 Claude 自动寻找对齐失败缓解方法的实验结果。相比只由模型提供方内部判断风险，这些动作更强调明确的通过标准、外部研究参与、可复用基准和跨模型验证。

与 2026-W35 相比，本期从生产 agent 的 API 和软件交付方法，转向 agent 的连续使用体验、浏览器执行环境以及科研场景扩展。Model Hardware Standard 又把 MCP 式接入从软件工具延伸到实验室和工业设备。总体信号是，Anthropic 正扩大 Claude 能记住什么、能操作什么和能进入哪些组织场景，同时把权限、隔离、评测和人工审批作为扩展能力的必要条件。

## 主题一：记忆与浏览器能力把 Claude 推向连续执行的工作入口

8 月 25 日，Claude 的记忆在 chat 与 Claude Cowork 之间打通。用户在聊天中积累的上下文可用于 Cowork 云端任务，Cowork 中形成的信息也能回到 chat。记忆按主题呈现，用户可以查看、编辑、删除、暂停或重置；敏感主题默认不写入。这次更新的重点不是单纯延长上下文，而是让长期信息在不同任务入口间可携带，同时保留可见的用户控制。

8 月 26 日，Claude in Chrome 面向所有 Claude 付费计划正式推出，可利用用户已登录的浏览器状态跨标签读取、点击、输入、导航和填写表单。Anthropic 同日为 Cowork 增加独立内置浏览器，默认不访问用户原有浏览器的标签、书签和密码。两种模式形成清晰分工：前者适合在现有会话中协助操作，后者适合把相对独立的 Web 任务交给 Claude，并降低与个人浏览环境混合的风险。

官方强调提示注入风险无法彻底消除，并为浏览器动作增加安全分类器。这说明浏览器 agent 的正式可用并不等于风险已经解决；用户和企业仍需根据任务敏感度选择环境、限制授权，并保留对关键动作的检查。

## 主题二：Agent 改进从临时调参变成可审阅的反馈循环

Warp 分享了一套基于 Agent Skills 的自改进方法：内层 skill 保存领域知识并执行任务，外层 improver skill 定期汇总人类反馈，只提出小而可审阅的修改，再通过普通 PR 和代码审查合并。流程已用于代码审查、规格编写和 issue 分流。

这套方法延续了 2026-W35 对 skills、eval 和版本化上下文的强调，但进一步回答了部署后的维护问题。有效反馈需要来自真实工作流和领域专家，改进需要有理由、可回滚，并用确定性评测验证。所谓“自改进”并非让 agent 自行改写生产规则，而是把反馈整理、变更建议和验证纳入已有工程治理。

## 主题三：安全研究正同时引入外部检验和自动化研究能力

Anthropic 启动 500 万美元用户福祉评测资助计划，重点覆盖陪伴、情绪支持、心理健康危机和多轮对话风险。官方要求评测明确通过与失败标准，引入临床和主题专家，并同时测试过度顺从与过度拒答。这把“用户福祉”从原则性讨论推进到可共享的评测与基准建设。

另一项试点通过 Anthropic Insights，让斯坦福、牛津和 METR 在不接触原始对话的情况下，对约 25 万条 Claude.ai 或 Claude Code 对话进行独立聚合分析。Anthropic 同时公开各项目的聚合数据并征集后续研究者。它为研究真实 AI 使用提供了一条隐私保护路径，但能否扩展仍取决于隐私审查和研究方法调校成本。

8 月 28 日的研究则显示，Claude 可自主训练模型，缓解欺骗、谄媚和越狱等 10 类对齐失败；较好的方法可迁移到留出基准、多轮对抗评测和更大模型。结果说明自动化研究者已能提出并验证部分可迁移缓解方法，但官方也明确承认现有基准覆盖有限，不能据此推断生产风险已经得到全面控制。

## 主题四：科研扩展同时覆盖设备标准、使用资源和风险边界

Model Hardware Standard（MHS）研究预览尝试为显微镜、移液工作站和机械臂等物理设备建立共享接入规范。它兼容 MCP、命令行和 API，也不绑定特定模型或 agent harness。若后续形成开放标准，agent 工具生态可能从软件接口进一步扩展到实验和制造设备；当前仍需观察安全评测、硬件适配成本和开源安排。

Anthropic 同时面向全球科学家提供 10,000 个 Claude 团队计划名额，并把 AI for Science 使用额度扩展到更多学科。资源投入降低了科研团队试用 Claude 的门槛，但官方继续对生物和药物开发查询保留按模型分级的双重用途限制。科研扩展的路线因此很清楚：扩大通用研究支持，同时对高风险能力保持差异化访问。

## 主题五：企业与教育采用开始强调组织级部署条件

Bain & Company 成为 Claude Partner Network 的 Global Premier partner，并披露已向 1.9 万名员工推广 Claude.ai、Cowork、Claude Code、Claude for Excel 和 Claude for Microsoft 365。Bain 将自身采用经验转化为客户咨询、治理、培训和技术现代化服务，说明 Anthropic 正借助大型咨询机构把产品组合带入企业转型项目，而非只提供模型接入。

Claude Tag 的内部案例则展示了在 Slack 中整理客户材料、汇总产品问题和预审营销法务内容的具体工作流。Claude 只在获授权的频道和文档范围内搜索与回帖，员工负责补充来源、核验事实和作出最终判断。这再次说明，群聊 agent 的效果与权限范围、频道指令和人工复核直接相关。

教育侧，Claude for Teachers 从个人教师计划扩展到美国 K-12 学校和学区，可统一管理账号，并提供单点登录、角色权限、域名接管和按 FERPA 要求设计的数据处理协议。相较 2026-W35 对 AI fluency 的通用教育投入，这次更新更进一步补齐了学区级部署所需的管理、隐私和教学工作流。
