# Anthropic 官方动态周报（2026-W45）

## 本期最重要的信号

已有日报中最值得关注的是，长时间运行的 agent 开始有更具体的性能和成本管理办法：11 月 2 日的 message threads 公测减少重复传输会话的开销，10 月 27 日的 Google Cloud 实践则把使用量追踪与预算控制结合起来。两者分别回答“怎样更快”和“如何判断投入价值”，不能把传输提速直接理解为 token 用量下降。

另一条重要信号来自专家判断研究：有专家参与，并不意味着判断独立于 agent。它与同日面向财务顾问的工作流、药物研发进展一起，提示读者区分流程接入、人工审阅与结果验证。本期缺失 10 月 28—31 日四份日报，以下仅总结已覆盖日期，不能据此判断整周发布节奏。

## 长任务优化从运行能力延伸到传输效率与成本核算

11 月 2 日，Claude Platform 开放 Messages API 的 message threads 公测。首次请求发送完整会话，此后发送新增消息及上次响应 ID，减少重复传输历史消息。官方称，在已默认启用该功能的大多数 Claude Code 用户中，50 万至 100 万 token 请求的首 token 延迟中位数下降约 35%。这项数字对应特定请求规模和用户范围，不代表所有任务都能获得同等提升。[message threads 公告](https://claude.com/resources/articles/message-threads)

线程在内存中加密保存，不写入磁盘，最后一次请求后 5 分钟过期；客户端届时需重新发送完整会话。模型每轮仍读取完整上下文，token 用量不变。对持续活跃的编码、电脑操作和图文密集任务，值得关注的是传输等待时间，以及过期后重新发送会话的处理方式。

10 月 27 日的 Google Cloud 成本管理文章提供了另一层实践：用预算、账单导出与配额管理消费，结合 Claude apps gateway 的身份管理、模型白名单和消费上限，再通过 OpenTelemetry 按用户、团队、模型和工具观察使用情况。其价值在于把成本与具体任务的产出对应起来；仅有消费统计，还不足以证明 ROI。[成本管理与 ROI](https://claude.com/resources/articles/how-to-manage-costs-and-demonstrate-roi-for-claude-code-on-google-cloud)

相比上一期的后台执行、云环境隔离和预算配置，本期已有材料增加了传输优化与使用观测细节。Engineering 栏目在已覆盖日期没有新增，工程信号主要来自 Claude Blog，沿用日报分类。

## 专业工作流扩大，人工审阅仍需检查判断依据

10 月 27 日，Claude for Financial Advisors 将托管机构、投资组合平台、CRM 和规划工具接入 Claude，并提供会前准备、组合偏离检查、会后记录及合规审阅辅助等 skills。机构可调整 skills 适配自身流程。这延续了上一期非营利组织插件的做法：把连接器、组织资料与日常工作步骤放到一起，但不能据公告认定业务收益或合规效果已经得到验证。[财务顾问工作流](https://claude.com/resources/articles/claude-for-financial-advisors)

同日的专家判断研究为这类工作流提供了一个需要检查的问题。研究让 50 名专业分析师使用 Claude Code 完成统计分析，并随机设置 agent 对合理选项的偏好；四项分析选择中，86% 的选择与 agent 偏好一致。事后多数人使用了 agent 的论据，少数明确归因于 agent。研究人为强化了模型偏好，实际工作中的影响幅度仍不确定，也不能直接将比例套用到财务顾问场景。[专家判断研究](https://www.anthropic.com/research/agents-judgment-calls)

两篇材料合起来的启示是：审阅除了确认输出，还应检查分析口径和备选方案是否已被 agent 的建议限定。上一期重点在操作是否获准，本期研究进一步涉及批准者如何形成判断；这是基于材料的分析，并非官方已经验证的通用解决方案。

## 药物研发提供早期实践，政府采用增加采购安排

10 月 27 日，Anthropic 披露与六家药物研发机构合作，涉及分子设计、候选药物优化、生产文档审核和临床试验规划，并开展自身药物发现项目。相比上一期生命科学合作招募，本期增加了研发环节的早期实践；多数成果仍处于临床前阶段，不能视为已证实的临床疗效。读者应关注模型建议如何进入实验验证，而不是把流程覆盖范围等同于药物研发成功率。[药物研发进展](https://www.anthropic.com/research/early-progress-drug-development)

同日，GSA 合作扩大至州、地方、部落和领地政府，为政府客户提供 Claude Enterprise、Claude for Government 和 Claude API 的 40% 折扣，无最低消费承诺。直接采购已适用，云服务商渠道计划在未来数月接入。这是采购条件的变化，尚不能据此判断实际采用规模；不同产品的安全认证范围与渠道接入时间仍需分别确认。[GSA 合作](https://www.anthropic.com/news/expanding-partnership-gsa)

本期已覆盖日报没有 Economic Futures 新条目，也不足以更新上一期关于公司治理和资本进程的判断。日报缺失期间是否存在相关发布，本报告不作推断。
