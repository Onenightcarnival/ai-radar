## Claude Blog

### Compliance API coverage extends to Claude Cowork and Claude Code
- 链接：[https://claude.com/blog/compliance-api-cowork-and-claude-code](https://claude.com/blog/compliance-api-cowork-and-claude-code)
- 发布时间：2026-08-11
- 类型：企业 AI、产品公告
- 摘要：Claude 的 Compliance API 现已在 beta 阶段覆盖 Claude Enterprise 客户使用的 Cowork（桌面端、网页端和移动端）以及 Claude Code（CLI 和桌面端）。合规与安全团队可以沿用现有接口和访问密钥，统一导出会话提示词、回复、工具调用、技能与制品内容，以及用户、组织、消息和时间戳等元数据；现有 Claude 聊天数据接口不受影响。
- 关注点：这项更新补齐了 Cowork 和 Claude Code 的审计与电子取证可见性，让企业不必为不同使用界面分别建设日志基础设施。需要注意，本次 beta 尚未覆盖网页版 Claude Code、通过 Claude Platform 访问的 Claude Code，以及在 Amazon Bedrock、Google Cloud Vertex AI 或 Microsoft Foundry 上运行的会话。
