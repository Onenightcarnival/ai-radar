## Claude Blog

### Turn artifacts into Mac and Windows apps

- 日期：2026-11-24
- 链接：[Turn artifacts into Mac and Windows apps](https://claude.com/resources/articles/install-as-app)
- 摘要：Claude 在 Mac 和 Windows 上逐步开放“Install as app”测试功能，让 Artifacts 以独立窗口和图标运行、分享，并随原始 Artifact 更新。应用可调用 Claude 和连接器，相关请求计入套餐用量。
- 关注点：应用权限分为默认、应用权限和完整电脑访问三级，更新后需重新授权。Enterprise 默认关闭此功能，需组织所有者启用；启动应用仍需联网并登录 Claude。

### MCP servers can now ship skills, run tasks, and more with Claude

- 日期：2026-11-24
- 链接：[MCP servers can now ship skills, run tasks, and more with Claude](https://claude.com/resources/articles/skills-over-mcp-tasks-and-more)
- 摘要：Skills over MCP 开放公开测试，服务器可随工具分发按需加载的技能。Tasks 和 Elicitation 正式可用，分别支持后台长任务和执行过程中向用户请求输入；文件上传能力即将推出。
- 关注点：开发者可把操作工具与使用指导一起维护，并为长流程加入异步执行和确认环节。不同套餐的开放进度不同，其中 Skills over MCP 尚待面向 Enterprise 推出。
