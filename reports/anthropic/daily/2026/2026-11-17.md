### Claude solves two open problems in the physics of black holes
- 链接：[Claude solves two open problems in the physics of black holes](https://www.anthropic.com/research/claude-black-hole-physics)
- 发布时间：2026-11-17
- 类型：科学研究
- 摘要：Anthropic 报告 Claude 完成两项黑洞理论研究：计算表明，相关量子理论在弱耦合下仍存在突变式相变；另一项结果给出最简模自举方法对最轻黑洞质量约束的精确极限，并证明该方法无法进一步收紧这一界限。

## Claude Blog

### Linked billing on the Claude Platform
- 链接：[Linked billing on the Claude Platform](https://claude.com/resources/articles/linked-billing-on-claude-platform)
- 发布时间：2026-11-17
- 类型：开发者平台
- 摘要：Claude Platform 推出关联计费（linked billing）测试版。客户可将自己的组织关联到第三方平台，由 Anthropic 直接结算 API 用量，无需向平台交出 API 密钥。客户可为各平台设置月度支出上限、查看费用并随时解除关联；平台可按请求选择由自己或客户付费。
- 关注点：这让编码代理和工作流工具减少密钥托管及计费开发工作。但请求仍在第三方平台的组织内运行，客户组织的 IP 白名单、加密密钥和数据保留设置不会随计费关联一起生效，接入时需单独确认这些控制。

### Using a "chaos loop" to harden the Claude Docs launch
- 链接：[Using a "chaos loop" to harden the Claude Docs launch](https://claude.dev/blog/chaos-loop-claude-docs-launch/)
- 发布时间：2026-11-17
- 类型：工程实践
- 摘要：Claude Blog 官方列表收录了 Claude Docs 上线前的压测复盘：团队让 Claude 在预发布集群持续运行两周，循环执行负载测试、读取遥测、提出修复并重新验证。官方报告上线后累计 20 亿次请求中出现 60 次服务器错误；一次内存问题修复将单文档峰值内存从约 3 GB 降至约 180 MB。
- 关注点：可复现的测试环境、可追溯到代码的遥测，以及“已确认的编辑不能丢失”等明确约束，是代理持续优化的基础；数据库结构等难以撤销的变更仍需人工批准。
