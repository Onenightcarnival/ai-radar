### Claude 参与药物研发的早期进展

### AI agent 如何影响专家判断

- 日期：2026-10-27
- 摘要：研究让 50 名专业分析师使用 Claude Code 完成统计分析，并随机设置 agent 对合理选项的偏好。四项分析选择中，分析师有 86% 的选择与 agent 偏好一致；事后解释时，多数人使用了 agent 的论据，只有少数明确归因于 agent。研究人为强化了模型偏好，实际工作中的影响幅度仍不确定。
- 链接：[AI agent 如何影响专家判断](https://www.anthropic.com/research/agents-judgment-calls)
- 关注点：人工审核是否独立，不能只看专家是否参与；应关注 agent 对分析口径和判断依据的影响。
