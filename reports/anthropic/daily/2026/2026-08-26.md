### Enabling independent research on how people use Claude
- 链接：[https://www.anthropic.com/research/enabling-independent-research](https://www.anthropic.com/research/enabling-independent-research)
- 发布时间：2026-08-26
- 类型：社会影响研究
- 摘要：Anthropic 公布了一项外部研究试点：斯坦福 SALT Lab、牛津 Human Information Processing Lab 和 METR 通过隐私保护工具 Anthropic Insights，对约 25 万条 Claude.ai 或 Claude Code 对话进行独立聚合分析。Anthropic 同时公开各项目的聚合数据，并征集后续研究者。
- 关注点：这项试点试图在不暴露原始对话的前提下，让外部团队独立研究真实 AI 使用。下一个关键问题是如何降低隐私审查与方法调校的成本，使计划可扩展。

## Claude Blog

### How Warp builds self-improving agents on Claude
- 链接：[https://claude.com/blog/how-warp-builds-self-improving-agents-on-claude](https://claude.com/blog/how-warp-builds-self-improving-agents-on-claude)
- 发布时间：2026-08-26
- 类型：Agent 工程
- 摘要：Warp 介绍了一套基于 Agent Skills 的自改进循环：内层 skill 保存领域知识并执行任务，外层 improver skill 定期汇总人类反馈，为内层 skill 提出小而可审阅的修改。更新通过常规 PR 和代码审查合并，已用于代码审查、规格编写和 issue 分流。
- 关注点：文章给出了可复用的 agent 改进模式：把反馈放在现有工作流里，优先收集有理由的专家反馈，用确定性评测验证改进，并保留人工审批。

### Claude in Chrome is generally available
- 链接：[https://claude.com/blog/claude-in-chrome-generally-available](https://claude.com/blog/claude-in-chrome-generally-available)
- 发布时间：2026-08-26
- 类型：产品发布
- 摘要：Claude in Chrome 现已面向所有 Claude 付费计划正式推出。Claude 可在用户已登录的浏览器中跨标签读取、输入、点击、导航和填写表单，也可在不逐步请求批准的情况下执行动作；每个动作执行前都会经过安全分类器校验。
- 关注点：浏览器 agent 从试点进入全面可用，核心前提是 Anthropic 对提示注入的模型训练、探针和动作分类器做了更多防护；官方仍明确表示风险无法彻底消除。

### Claude gets its own browser in Cowork
- 链接：[https://claude.com/blog/cowork-built-in-browser](https://claude.com/blog/cowork-built-in-browser)
- 发布时间：2026-08-26
- 类型：产品发布
- 摘要：Claude Cowork 桌面应用新增独立内置浏览器，Claude 可在侧边栏中打开网站、读取页面、点击和填表，无需安装扩展，也不会默认访问用户原有浏览器的标签、书签和密码。该功能正陆续面向 Pro、Max 和 Team 计划推出，Enterprise 管理员可直接启用。
- 关注点：Anthropic 将两类浏览器工作分开：Claude in Chrome 操作用户当前页面和登录状态，Cowork 内置浏览器则用于把独立 Web 任务交给 Claude，同时保持与个人浏览器隔离。
