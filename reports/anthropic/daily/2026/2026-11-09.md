## Anthropic Research

### Claude 完成三类电子设备的原型设计
- 日期：2026-11-09
- 链接：[Testing Claude on real-world electronics design](https://www.anthropic.com/research/claude-electronics-design)
- 摘要：Anthropic 与 Diode Computers 合作，让 Fable 5.2 根据简短需求设计扬声电话、语音助手中枢和掌上虚拟宠物。Claude 完成元件选择、电路板布局布线、外壳建模与固件编写，并指导工程师制造和测试；三款原型均无需修改电路即可运行。
- 关注点：文章具体展示了模型如何处理几何约束、制造检查和设计返工。这些仍是原型，尚未完成电气验证、天线调试、热测试或认证，不能据此视为可量产产品。

### 摩根大通将 Claude Code 推广至更多业务团队
- 日期：2026-11-09
- 链接：[JPMorganChase expands Claude Code to more employees across the firm](https://claude.com/resources/articles/jpmorganchase-expands-claude-code)
- 摘要：摩根大通把 Claude 的使用范围从工程师扩展到产品和业务团队，用于需求拆解、风险与控制评估及项目规划。工程团队也用它推进旧系统改造、代码审查和运维分析。Claude Code 在该行自有基础设施上的受控环境运行，新模型需经内部审批。
