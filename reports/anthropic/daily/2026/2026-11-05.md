## Claude Blog

### Claude 推出个人财务功能
- 日期：2026-11-05
- 原文：Introducing Personal Finance in Claude
- 链接：https://claude.com/resources/articles/introducing-personal-finance-in-claude
- 摘要：Personal Finance 本周开始向美国 Pro、Max 和 Ultra 用户推出测试版。用户可通过 Plaid 以只读方式连接银行和信用卡账户，让 Claude 汇总收支、解释费用并生成图表；该功能不能转移、管理或投资资金。专属财务区域内的对话不用于训练模型。
- 关注点：产品将账户数据接入自然语言分析，使用时需注意授权范围、财务区域与普通对话的隐私规则差异，并核对重要金额。

### Claude Enterprise 增加安全与管理控制
- 日期：2026-11-05
- 原文：More visibility and control over Claude Enterprise for security teams
- 链接：https://claude.com/resources/articles/claude-enterprise-security-updates
- 摘要：Claude Enterprise 新增安全中心、集中管理和访问控制。提示词与工具调用前的 inference hooks 已正式开放，可接入企业现有的数据安全检查；安全中心、集中管理、Admin API 强制登出及自助 IP 白名单等功能仍处于测试阶段。文章还介绍了在本地 Cowork 虚拟机内运行企业 EDR 传感器的集成。
- 关注点：企业应区分各项控制的覆盖范围：强制登出不会撤销 API 密钥或停止已运行的云端会话，EDR 集成目前只检测并上报活动，不负责阻断。
