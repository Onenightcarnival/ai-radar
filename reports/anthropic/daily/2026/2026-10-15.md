## Anthropic News

### 向 METR 开放内部访问，推进独立安全评估

- 链接：[An update on independent evaluators](https://www.anthropic.com/news/an-update-on-independent-evaluators)
- 发布时间：2026-10-15
- 类型：安全与治理
- 摘要：Anthropic 已为 6 名 METR 员工提供公司设备、办公空间及内部工具和系统权限，访问范围大致与其风险评估团队相当，但客户数据、法律保密信息和模型架构等类别受到限制。METR 可公开发布风险、事件和实践评估，Anthropic 无权否决发布，但可要求删去预先界定的敏感信息；METR 可公开评价删减是否合理。
- 关注点：评估者能获得多少内部信息、能否独立发布结论，是此次安排的关键。Anthropic 正设计三级访问机制；SecureBio、Accenture 等其他合作仍处于较早阶段，访问权限和发布权更有限，不能视为已获得与 METR 相同的条件。

## Claude Blog

### Code Review 正式开放，可按仓库选择审查深度

- 链接：[Code Review is now generally available](https://claude.com/resources/articles/code-review-is-now-generally-available)
- 发布时间：2026-10-15
- 类型：开发者工具与代码审查
- 摘要：Claude Code 的 Code Review 结束研究预览，向 Team 和 Enterprise 组织正式开放。官方称，多数审查耗时已从约 20 分钟缩短至 6—10 分钟，并改进问题说明，使其更清楚地交代缺陷、触发条件和修复方式。管理员可为每个仓库选择 Quick、Standard（默认）或 Deep 三档审查深度。
- 关注点：管理员启用功能、安装 GitHub App 并选定仓库后，新 PR 会自动触发审查。团队可按仓库的重要程度选择审查档位；官方披露的速度改善可供试用时参考，实际效果仍需结合自身代码库验证。

### Claude Code 团队如何按风险安排代码审查

- 链接：[How the Claude Code team does code review](https://claude.dev/blog/solving-code-review-at-anthropic/)
- 发布时间：2026-10-15
- 类型：工程实践与代码审查
- 摘要：Claude Code 团队介绍从提交前验证、AI 审查、安全检查到按风险分级人工批准、合并队列和回滚的完整流程。自动审查发现的问题需被修复或说明关闭理由；团队用历史事故构建评估集，并限制重复审查轮数，避免 agent 在修复与审查之间反复循环。
- 关注点：低风险变更在特定可信作者和检查条件下可减少人工批准，但高风险路径仍需人工负责，agent 批准不能替代必需的人工批准。团队以回滚和事故率约束审查提速，文章描述的内部流程也不等同于公开 Code Review 产品的全部能力。
