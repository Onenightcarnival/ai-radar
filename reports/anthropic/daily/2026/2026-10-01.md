## Claude Blog

### Customize Claude Code with mods

- 链接：[https://claude.com/blog/claude-code-mods](https://claude.com/blog/claude-code-mods)
- 发布时间：2026-10-01
- 类型：工程与开发者平台 / Claude Code 扩展
- 摘要：Claude Code 推出 mods，开发者可用 TypeScript 函数在事件前后运行代码或替换事件，改写提示词、拦截工具调用、处理权限请求，也能添加界面和替换内置功能。Mods 随插件分发，支持 CLI 和桌面端；开发者还可让 Claude 编写、安装并热加载 mod。
- 关注点：Mods 不在沙箱中运行，拥有与 Claude Code 相同的本机访问权限。团队部署需关注插件来源、加载顺序和权限规则；Team、Enterprise 及受管理设备默认优先加载 sec-default，限制用户安装的 mods 覆盖拒绝规则等行为。
