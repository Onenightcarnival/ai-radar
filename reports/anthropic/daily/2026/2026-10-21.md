### 1. Claude Duet 开放研究预览候补申请

- 日期：2026-10-21
- 链接：[Introducing Claude Duet](https://claude.com/resources/articles/claude-duet)
- 摘要：Claude Duet 是面向专业人士和小企业主的主动式 agent，可读取已连接应用、发送工作简报，并在云端虚拟机中持续处理任务。研究预览先向美国 Pro 和 Max 用户开放候补申请，与现有 Claude 共用额度，后台检查也计入用量。
- 关注点：产品将定期检查、后台执行和审批串在同一工作流中；发送消息、付款、签署文件或删除内容前仍需用户批准。目前还是早期版本，可能误判紧急程度，且暂不能向用户展示浏览器过程。

### 2. Claude Security 增加持续扫描与修复跟踪

- 日期：2026-10-21
- 链接：[Claude Security now scans continuously and tracks fixes](https://claude.com/resources/articles/claude-security-now-scans-continuously-and-tracks-fixes)
- 摘要：Claude Security 向 Enterprise 客户开放新版公测。连接代码库后，先进行基线扫描，再根据变更的风险与复杂程度定期扫描；修复合入后自动关闭发现项，问题再次出现时重新打开。项目知识库和可编辑威胁模型用于补充部署环境与安全策略。
- 关注点：新增 API、Webhooks 和 MCP 连接器，便于把发现、研判和修复接入现有开发流程；多仓库分析与角色权限控制也让安全团队更容易组织跨服务排查。

### 3. HCLTech 成为 Claude 全球高级合作伙伴

- 日期：2026-10-21
- 链接：[HCLTech joins the Claude Partner Network as a Global Premier partner](https://claude.com/resources/articles/hcltech-joins-claude-partner-network)
- 摘要：HCLTech 加入 Claude Partner Network，成为 Global Premier Partner，计划设立专门业务部门和卓越中心，将 Claude 嵌入部分 HCLSoftware 产品，并把 Claude 与 Claude Code 接入其 IT 服务平台 AI Force。合作面向金融、医疗、制造等行业。
- 关注点：落地安排包括客户沙箱测试、员工培训、策略约束和人工审核；涉及客户生产系统的变更由 HCLTech 工程师审查批准，可作为企业部署 agent 时组织与流程设计的参考。
