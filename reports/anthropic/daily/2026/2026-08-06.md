### Run Claude Code sessions on your own compute
- 链接：[https://claude.com/blog/run-claude-code-sessions-on-your-own-compute](https://claude.com/blog/run-claude-code-sessions-on-your-own-compute)
- 发布时间：2026-08-06
- 类型：Product announcements / Claude Code
- 摘要：Claude Blog 宣布 self-hosted environments 进入 public beta，允许团队把 Claude Code session 跑在自己的基础设施上。用户仍可从 web、mobile、desktop 或 routine 启动 session，但执行环境位于企业网络内部，贴近内部服务、工具链和安全控制；官方同时说明，对多数企业仍推荐托管方案，self-hosted 更适合有网络、工具或合规要求的团队。
- 关注点：这是 Claude Code 面向企业工程平台的重要部署选项。需要重点关注数据边界和运维责任：代码 checkout、构建产物、密钥和 session 产生或修改的文件留在客户基础设施上，但对话、回复和 tool results 会发送给 Anthropic 做推理，并保存 transcript 以支持跨端继续会话。

### Millennium and Anthropic are building a digital risk analyst with Claude
- 链接：[https://claude.com/blog/millennium-and-anthropic-are-building-a-digital-risk-analyst-with-claude](https://claude.com/blog/millennium-and-anthropic-are-building-a-digital-risk-analyst-with-claude)
- 发布时间：2026-08-06
- 类型：Enterprise AI Agents / Claude Code / Product / Claude Enterprise
- 摘要：Claude Blog 介绍 Anthropic 正与 Millennium 合作开发 digital risk analyst，用 Claude 帮助风险管理团队发现新的风险洞察，并围绕不同资产类别形成风险敞口判断。该系统面向 Millennium 的专有数据和核心风险工作流，强调能保留并回忆历史信息、解释每日风险变化，再由 Millennium 的人工风险经理验证和补充。
- 关注点：这是 Claude 在金融服务核心工作流中的企业 agent 案例。对金融机构和企业平台团队，重点是它把 Claude、Claude Code 和内部 AI lab 结合起来，同时强调可审计分析、沙盒测试、人类审批，以及在复杂高要求环境中保留人工判断。
