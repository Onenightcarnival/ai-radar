### Migrating our Messages API to Rust

- 日期：2026-11-25
- 链接：[Migrating our Messages API to Rust](https://www.anthropic.com/research/migrating-api-to-rust)
- 摘要：Anthropic 分享了将 Messages API 从 Python 迁移到 Rust 的过程。团队以现有生产系统为对照，通过影子流量逐步核验输入、输出和计费行为，并让 Claude 根据差异记录定位和修复问题。官方报告称，迁移后每次请求的 CPU 用量下降约 70%，首个 token 的中位等待时间缩短约 20%。
- 关注点：模型只调用一次，再将输出回放给 Rust，避免模型随机性干扰比较；差异记录不包含用户请求正文。快速本地验证、生产流量复核和经验记忆共同支持修复流程，但修复是否适合上线仍需人工判断。
