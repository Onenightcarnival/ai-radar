### Improving Fable 5's biology safeguards
- 链接：[https://www.anthropic.com/news/improving-fable-5-s-biology-safeguards](https://www.anthropic.com/news/improving-fable-5-s-biology-safeguards)
- 发布时间：2026-08-07
- 类型：Product / Announcements / Safety
- 摘要：Anthropic 更新了 Claude Fable 5 的生物学安全防护，目标是在维持高风险双用途场景管控的同时，减少普通生物和健康相关问题触发降级的情况。官方称测试中生物相关 fallbacks 在产品表面减少约 85%，日常健康、教育和部分临床任务会更少被切到能力较低的模型；但涉及病毒学、毒理学、分子设计等双用途请求仍会回退到 Opus 5。

## Claude Blog

### Running auto mode in production
- 链接：[https://claude.com/blog/auto-mode-in-production](https://claude.com/blog/auto-mode-in-production)
- 发布时间：2026-08-07
- 类型：Claude Code / Product / Customer Stories
- 摘要：Claude Blog 介绍 Nuro、Gusto 和 Garner Health 在生产环境中使用 Claude Code auto mode 的做法。auto mode 不再要求用户逐条审批命令，而是用分类器拦截可能有害的动作；Anthropic 称内部评测中该机制比开发者手动点权限提示更能抓住危险动作，并让 Claude Code 在两次中断之间工作的时间提升到原默认模式的 9 倍。
- 关注点：这篇文章把 auto mode 从功能说明推进到生产实践。对工程组织，关键信号是 Anthropic 正在把长时间运行、多会话并行、评测驱动迭代的 agentic coding 工作流，包装成可落地的安全默认体验。

### Auto mode is now the default in Claude Code for Pro, Max, and Team plans
- 链接：[https://claude.com/blog/auto-mode-default-in-claude-code](https://claude.com/blog/auto-mode-default-in-claude-code)
- 发布时间：2026-08-07
- 类型：Claude Code / Product
- 摘要：Anthropic 宣布 Claude Code 将从 8 月 14 日起，在 Pro、Max 和 Team 计划的新会话中默认启用 auto mode；如果用户已经固定了其他默认模式，则不会改变。auto mode 的分类器开销不再向这些计划的 Claude Code 用户计费。Enterprise、API、AWS、Bedrock、Google Cloud Agent Platform 和 Microsoft Foundry 目前仍保持 opt-in，Anthropic 计划在接下来一个月与云合作伙伴推进默认启用。
- 关注点：这是 Claude Code 权限模型的一次默认行为变化。开发团队需要关注托管设置、权限策略和高风险命令 guardrails，因为 Anthropic 正把“少打断但可拦截危险动作”作为 Claude Code 面向长任务的标准交互。
