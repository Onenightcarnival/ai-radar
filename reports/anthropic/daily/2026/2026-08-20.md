- 链接：[https://claude.com/blog/claude-code-guide-for-startups](https://claude.com/blog/claude-code-guide-for-startups)
- 发布时间：2026-08-20
- 类型：Claude Code / 开发者实践
- 摘要：Anthropic 基于十多家快速增长创业公司的访谈，总结 Claude Code 在 AI-native 产品开发中的五条实践：让更多角色能从问题直接做出原型，自动化软件生命周期里的重复环节，用评测和审查机制约束 agent 输出，把团队规范写进技能、`CLAUDE.md` 和流程，并通过原型、内部试用和生产化形成反馈循环。
- 关注点：这篇文章把 Claude Code 从“写代码工具”扩展成创业公司组织方式和 SDLC 设计问题。值得关注的是 Anthropic 反复强调的不是完全放手自动合并，而是连接真实工具、沉淀可共享技能、维护 golden set、让领域专家参与反馈，并把高风险场景交给可审计流程。

### How monday.com transformed its platform into an agent-first product where humans and agents collaborate
- 链接：[https://claude.com/blog/how-monday-com-transformed-its-platform-into-an-agent-first-product-where-humans-and-agents-collaborate](https://claude.com/blog/how-monday-com-transformed-its-platform-into-an-agent-first-product-where-humans-and-agents-collaborate)
- 发布时间：2026-08-20
- 类型：Agent / 企业产品
- 摘要：monday.com 分享其从“给既有工作流撒上 AI 功能”转向 agent-first 平台的经验。文章称 monday 围绕 Claude 重构产品，让 agent 使用既有的上下文、工作流、看板、权限和治理能力参与工作；自 2026 年 5 月上线以来，客户已与平台内 agent 发生超过 500 万次交互。
- 关注点：这篇案例强调企业 agent 的采用门槛不只是模型能力，而是 agent 是否嵌入用户已经工作的地方。monday 的做法把 agent 设计成可被分配任务的“队友”，覆盖 IT 工单、知识库维护、候选人筛选、销售简报和会议准备等流程，重点信号是权限、治理和工作流上下文正在成为企业 agent 产品的基础设施。

### Build production agents with computer use, the Skills API, and the Files API
- 链接：[https://claude.com/blog/computer-use-skills-api-files-api](https://claude.com/blog/computer-use-skills-api-files-api)
- 发布时间：2026-08-20
- 类型：产品发布 / Claude Platform
- 摘要：Anthropic 宣布 Claude Platform 上的 computer use、Skills API 和 Files API 正式可用，并为 computer use 增加新的 browser use tool。computer use 支持 agent 通过截图和页面结构操作软件与 Web 应用；Skills API 用于上传、版本化和复用团队技能；Files API 则提供文件读写与持久引用能力。
- 关注点：这是 2026-08-20 最直接的平台发布信号：Anthropic 正把生产级 agent 的三个关键能力打包为平台接口，即操作现有软件、加载组织知识和处理产出文件。官方还提到 computer use 单轮可执行多步动作、browser use 更可靠定位页面元素、Files API 提供 1 TB 组织级存储，并将能力扩展到 Microsoft Foundry，后续进入 Vertex AI。

### Anthropic’s approach to teaching and learning AI
- 链接：[https://claude.com/blog/anthropics-approach-to-teaching-and-learning-ai](https://claude.com/blog/anthropics-approach-to-teaching-and-learning-ai)
- 发布时间：2026-08-20
- 类型：AI 教育 / Claude Academy
- 摘要：Anthropic 介绍 Claude Academy 的教育理念，说明为什么要面向大众提供 AI 学习材料，以及其内部员工培训如何影响课程设计。文章强调 AI 教育应提升人的主动性，帮助个人和组织理解何时使用 AI、如何管理 agent 所知道的内容、如何审阅 AI 产出，以及如何在快速变化中持续学习。
