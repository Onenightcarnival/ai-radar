## Anthropic Research

### 1. 用 Claude 为 123 个开源库证明特定安全性质

- 日期：2026-10-22
- 链接：[LLMs are making formal software verification feasible at a much larger scale](https://www.anthropic.com/research/formal-verification)
- 摘要：Anthropic 与 Theorem 将模糊测试转换为形式化规格，让 Claude 修复发现的问题并生成由 Rocq 检查的证明。在数周内，团队为 123 个开源库的 239 个入口点证明了限定条件下不会崩溃，并公开部分证明及底层语义。
- 关注点：保证范围限定于小于 64 MB 的输入、固定内存预算下的单线程 RISC-V Linux 静态程序，仍依赖规格、机器与操作系统语义及证明检查器的正确性，不能等同于整个库没有漏洞。值得关注的是把现有测试转成可验证安全保证的工作流。

## Claude Blog

### 1. 何时将子 agent 合并到主循环

- 日期：2026-10-22
- 链接：[Building agents: When to fold subagents into your main agent loop](https://claude.com/resources/articles/building-agents-when-to-fold-subagents-into-your-main-agent-loop)
- 摘要：Anthropic 总结企业部署经验：将紧密关联的路由、规划和领域子 agent 合并到主循环，通过 skills 和工具搜索按需加载知识与工具，有时能提高质量并降低成本与延迟。文章提供迁移工具包，建议先建立端到端评测，再逐个比较合并效果。
- 关注点：子 agent 仍适用于独立验证、并行任务和权限隔离等场景。架构取舍应检查具体任务是否退化，并把硬性权限和审批约束放在工具或执行框架中，避免仅凭总体分数决定迁移。

### 2. Anthropic 托管的 Claude Platform 在 Google Cloud 正式可用

- 日期：2026-10-22
- 链接：[The full Claude Platform, available on Google Cloud](https://claude.com/resources/articles/claude-models-on-google-cloud-anthropic-managed)
- 摘要：Claude Models on Google Cloud（Anthropic managed）正式上线，支持完整 Claude API 功能，新功能和测试版与原生平台同日提供。客户可使用现有 Google Cloud IAM 凭据、统一账单，并将用量抵扣已有云消费承诺；目前提供 US 和 Global 端点。
- 关注点：该接入方式便于沿用 Google Cloud 的身份和采购安排，同时获取原生平台能力。由 Google 托管、由 Google 担任数据处理方的现有选项仍然保留，企业应按托管方式区分服务边界。
