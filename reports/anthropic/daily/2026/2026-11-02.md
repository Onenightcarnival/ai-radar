## Claude Blog

### Make long-running agents faster with message threads

- 日期：2026-11-02
- 链接：[官方文章](https://claude.com/resources/articles/message-threads)
- 摘要：Claude Platform 开放 message threads 公测。首次请求发送完整会话，后续只发送新增消息及上次响应 ID，减少长时间运行 agent 的请求传输开销。官方称，在已默认启用该功能的大多数 Claude Code 用户中，50 万至 100 万 token 请求的首 token 延迟中位数下降约 35%。
- 关注点：适合持续活跃的编码、电脑操作及图文密集工作流。线程在内存中加密保存，不写入磁盘；最后一次请求后 5 分钟过期，客户端需重新发送完整会话。模型每轮仍读取完整上下文，因此 token 用量不变。
