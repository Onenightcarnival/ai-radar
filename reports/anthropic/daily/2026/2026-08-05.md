## Claude Blog

### Inference hooks: inline data loss prevention for Claude Enterprise
- 链接：[https://claude.com/blog/claude-enterprise-inference-hooks](https://claude.com/blog/claude-enterprise-inference-hooks)
- 发布时间：2026-08-05
- 类型：Product announcements
- 摘要：Claude Blog 发布 Claude Enterprise 的 inference hooks beta。该能力让企业合规团队在 prompt、上下文和工具调用响应进入 Claude 之前进行检查并执行策略，覆盖 Claude Enterprise 的 chat、Claude Code、Claude Cowork，以及通过 MCP connectors、skills 和 plugins 发起的工具调用。组织可把请求经由签名 WebSocket 发到自有 DLP 或安全服务器，由服务器返回 allow/deny verdict，Claude 再实时执行。
- 关注点：这是 Claude Enterprise 在数据外泄防护和企业安全治理上的产品增强。对安全团队，重点是用一个组织级配置覆盖多种 Claude 使用界面，并接入 Netskope、Palo Alto Networks、Proofpoint、Zscaler 或自建 AI security server；对平台团队，重点是 shadow mode、角色排除、灰度 rollout、failure policy 和 timeout 等上线控制。
