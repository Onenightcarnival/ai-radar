## Anthropic News

### Introducing Claude Opus 5
- 链接：[https://www.anthropic.com/news/claude-opus-5](https://www.anthropic.com/news/claude-opus-5)
- 发布时间：2026-07-24
- 类型：模型与产品
- 摘要：Anthropic 发布 Claude Opus 5，定位为面向日常使用、长时间 agent、代码和专业知识工作的 Opus 级模型。官方称它接近 Claude Fable 5 的前沿智能，但价格为后者一半；它成为 Claude Max 默认模型、Claude Pro 最强模型，并在 Claude API 上以 `claude-opus-5` 提供，定价为每百万输入 token 5 美元、每百万输出 token 25 美元。
- 关注点：这次更新把 Opus 档位继续推向高强度代码、知识工作和企业任务，同时强调 effort setting、Fast mode、API 可用性和安全护栏。对开发者和企业用户来说，关键是 Anthropic 在用更细的模型档位和速度/成本选项承接长任务 agent 场景。

## Anthropic Research

### Frontier Red Team Project Pilot: Can AI control a drone?
- 链接：[https://www.anthropic.com/research/project-pilot](https://www.anthropic.com/research/project-pilot)
- 发布时间：2026-07-24
- 类型：研究与安全
- 摘要：Anthropic 与 Andon Labs 合作介绍 Drone-Bench，用来评估 AI 模型是否能自主控制无人机完成定位并跟随人员的任务。文章把真实飞行演示拆成重建、定位、导航、检测和跟随等子任务，并说明 Claude Fable 5 在多数子任务上已接近或超过基线，但端到端导航仍受重建误差影响。
- 关注点：这篇不是产品发布，而是把模型能力从软件 agent 延伸到硬件控制和物理世界风险评估。它强调自主监控、搜索救援、公共安全和滥用风险之间的双重用途张力，也延续了 Anthropic 用前沿红队评测提前识别治理问题的路线。

### The new rules of context engineering for Claude 5 generation models
- 链接：[https://claude.com/blog/the-new-rules-of-context-engineering-for-claude-5-generation-models](https://claude.com/blog/the-new-rules-of-context-engineering-for-claude-5-generation-models)
- 发布时间：2026-07-24
- 类型：工程与开发者平台
- 摘要：Claude Blog 总结 Claude 5 代模型下的 context engineering 新规则：Anthropic 在 Claude Code 中为 Opus 5、Fable 5 等新模型删除了超过 80% 的系统提示词，且代码评测没有可测损失。文章建议减少过度约束，把验证、代码审查等长说明拆成按需加载的 skills，用工具描述、CLAUDE.md、memory、artifacts 和引用文件承担不同层次的上下文。
- 关注点：这是面向 Claude Code 和自建 agent harness 的实践信号。重点变化是新模型更能处理判断和引用，团队应该把上下文从“大而全的规则库”改成轻量、分层、按需加载的工程体系。

- 链接：[https://claude.com/blog/how-the-product-designer-who-built-claude-design-uses-it-to-explore-ideas-before-building-them](https://claude.com/blog/how-the-product-designer-who-built-claude-design-uses-it-to-explore-ideas-before-building-them)
- 发布时间：2026-07-24

- 摘要：Anthropic 产品设计师 Nate Parrott 介绍 Claude Design 的内部起源和使用方式：它利用 Claude 擅长生成 HTML 的能力，把视觉想法做成可交互、可分享的原型、幻灯片、落地页、PDF、邮件和动画。文章说明 Claude Design 已在 Claude Pro、Max、Team 和 Enterprise 计划中以 beta 形式提供，并可与 Claude Code 在原型和实现之间往返协作。

### Claude models explained: choosing the best model for your use case
- 链接：[https://claude.com/blog/claude-models-explained-choosing-the-best-model-for-your-use-case](https://claude.com/blog/claude-models-explained-choosing-the-best-model-for-your-use-case)
- 发布时间：2026-07-24
- 类型：工程与开发者平台
- 摘要：Claude Blog 发布模型选择指南，解释 Mythos、Opus、Sonnet、Haiku 等模型档位的差异，并建议多数团队先从最强的通用可用模型开始，再用 effort level 调整质量、速度和成本。文章强调应关注 cost-per-task 而不只是 token 单价，并用真实工作负载或自建 eval 判断模型是否满足质量门槛。
- 关注点：这是 Anthropic 为多模型产品线提供的采用指南。它把模型选择从“哪个模型最便宜”转向“哪个模型在具体任务上总体成本最低、质量最稳”，也强化了企业团队建立持续 eval 的必要性。
