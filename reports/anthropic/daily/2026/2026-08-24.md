### How an Anthropic field marketer uses Claude Code to send weekly personalized updates to every sales rep
- 链接：[https://claude.com/blog/how-an-anthropic-field-marketer-uses-claude-code-to-send-weekly-personalized-updates-to-every-sales-rep](https://claude.com/blog/how-an-anthropic-field-marketer-uses-claude-code-to-send-weekly-personalized-updates-to-every-sales-rep)
- 发布时间：2026-08-24
- 类型：产品实践
- 摘要：Anthropic 市场团队的 Adam Ward 介绍了如何用 Claude Code 把每周销售材料自动转成面向每位销售代表的个性化 Monday briefing。流程会结合 BigQuery、CRM 和 Slack 中的客户与活动信息，为不同销售团队生成 Slack 私信，列出本周三项优先动作、相关活动、已报名联系人、可转发内容和后续建议。
- 关注点：这篇文章把 Claude Code 放进非工程团队的日常流程里，重点不在“会不会写代码”，而在能否把业务问题、模板、数据源和反馈规则讲清楚。值得关注的是它对 prompt 版本化、先小范围试点、用用户反馈沉淀硬规则，以及禁止 Claude 编造链接等实践的强调。
