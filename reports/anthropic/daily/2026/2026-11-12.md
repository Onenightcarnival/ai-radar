### 1. Managed Agents 推出自托管私测

- 日期：2026-11-12
- 链接：[官方原文](https://claude.com/resources/articles/self-hosted-claude-managed-agents)
- 摘要：企业可在自己的云环境或本地部署 Managed Agents，运行 agent 执行框架、沙箱、凭据管理和会话历史，并选择模型请求的发送位置。核心 API 与托管服务保持一致。

### 2. J.Crew 用 Claude 构建整套穿搭顾问

- 日期：2026-11-12
- 链接：[官方原文](https://claude.com/resources/articles/j-crew-style-advisor-with-claude)
- 摘要：J.Crew 上线 Style Advisor，让用户通过对话寻找整套穿搭，推荐素材来自品牌造型师的拍摄作品。团队用 Claude Code 开发原型，线上由 Sonnet 5.5 负责造型对话、Haiku 5.5 处理快速任务，首批面向美国男女装用户。

### 3. Claude for Manufacturing 发布

- 日期：2026-11-12
- 链接：[官方原文](https://claude.com/resources/articles/claude-for-manufacturing)
- 摘要：制造业插件提供 17 项技能和四个连接器，连接 Autodesk Fusion、Infor、Microsoft 365 与 Oracle NetSuite，支持报价、质量报告、故障分析和供应商询价等工作。Team 和 Enterprise 用户可安装使用。
- 关注点：流程以人工审核为终点，结果可追溯到底层记录；该插件不直接操作设备。

### 4. Claude Meetings 开始测试

- 日期：2026-11-12
- 链接：[官方原文](https://claude.com/resources/articles/claude-meetings)
- 摘要：Claude 可作为可见参会者加入 Google Meet，回答问题、编写纪要和待办，并在讨论中协作生成文档、白板等内容。功能开始向 Team 和 Enterprise 推出测试版，使用连接工具需获得用户授权。
- 关注点：关注管理员开关、外部参会者处理和会议资料可见范围；测试版暂不支持部分启用 ZDR、HIPAA-ready 或 CMEK 的组织。

### 5. Opus 5.5 日常知识工作指南

- 日期：2026-11-12
- 链接：[官方原文](https://claude.com/resources/articles/using-claude-opus-5-5-as-your-daily-driver-for-knowledge-work)
