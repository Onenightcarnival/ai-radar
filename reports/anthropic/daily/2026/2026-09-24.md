## Anthropic Research

### Project Swap: What happens when agents trade for us?

- 链接：[https://www.anthropic.com/research/project-swap](https://www.anthropic.com/research/project-swap)
- 发布时间：2026-09-24
- 类型：经济研究 / agent 交易实验
- 摘要：Anthropic 让六个办公室的 201 名员工各带一本书，由 Claude agent 根据简短访谈交换图书。agent 对成对图书的偏好判断与参与者一致的比例为 61%；实验中，交易结果与理想分配的差距主要来自偏好理解不准，模型选择对谈判结果的影响也大于指令差异。
- 关注点：委托 agent 交易前，可以用少量样例决策检查它是否理解用户偏好，并保留交易过程供用户复核。实验仅涉及内部员工和受控图书交换，结论仍需在更广泛的市场中验证。

## Claude Blog

### Coding sessions are longer and use more context. Claude Opus 5.5 is built with that in mind.

- 链接：[https://claude.com/blog/claude-opus-5-5-built-for-coding-sessions-that-use-more-context](https://claude.com/blog/claude-opus-5-5-built-for-coding-sessions-that-use-more-context)
- 发布时间：2026-09-24
- 类型：Claude Code / 使用成本
- 摘要：文章分析 Opus 5.5 如何降低长时间、高上下文编码任务的成本：输入和输出 token 单价下降 20%，缓存读取价格下降 60%，Claude Code 也改善了缓存复用。官方汇总数据显示，近半年每次请求的上下文增长了 2.6 倍，因此缓存读取成本对总账单的影响更大。
- 关注点：团队可用 /usage 检查缓存读取占比，并在长会话中减少不必要的缓存失效。按 token 计费的用户可考虑一小时缓存有效期；实际节省幅度仍取决于任务长度、缓存命中率和完成任务所需轮数。

### Claude Tag now supports personal connectors in channels

- 链接：[https://claude.com/blog/claude-tag-now-supports-personal-connectors-in-channels](https://claude.com/blog/claude-tag-now-supports-personal-connectors-in-channels)
- 发布时间：2026-09-24
- 类型：Claude Tag / 连接器与权限
- 摘要：Claude Tag 开始允许用户在 Slack 频道中调用自己已连接的日历、云盘或 CRM 等服务，个人连接器只能由本人发起使用。用户可选择先审核回复再发布，或由自动模式筛查敏感内容。该功能正向 Team 方案推出，Enterprise 随后跟进。
- 关注点：个人连接器适合有人监督的协作请求；定时任务和 Claude 自主发起的操作仍使用管理员配置的频道连接器。个人数据整理成回复后会对频道成员可见，发布前应按需要审核内容。
