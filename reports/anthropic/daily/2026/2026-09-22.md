### What a task costs on Opus 5.5

- 链接：[https://claude.com/blog/what-a-task-costs-on-opus-5-5](https://claude.com/blog/what-a-task-costs-on-opus-5-5)
- 发布时间：2026-09-22
- 类型：Claude Code / 成本管理
- 摘要：文章拆解 Claude Code 单次任务的成本：交互轮数、缓存读取、输出 token（含思考）和模型选择都会影响总费用。官方称，Opus 5.5 的 API 输入与输出单价较 Opus 5 降低 20%，缓存读取单价降低 60%；实际节省取决于任务的缓存占比和重试次数。文中还介绍了 effort 调整、提示词检查和上下文压缩的取舍。
- 关注点：开发团队可用 `/usage` 对比同一真实任务在两个模型上的轮数、输出量和估算费用，再决定模型与 effort 设置。文中成本示例未计入缓存写入，不能直接当作实际账单或固定节省比例。
