### Working with AI

- 日期：2026-11-23
- 链接：[Working with AI](https://www.anthropic.com/research/working-with-ai)
- 摘要：Anthropic 对 58 家企业客户进行了 66 次访谈。受访者描述的 AI 价值更多来自增加产出；直接裁员案例较少，但多数企业表示减少了招聘。高价值应用往往伴随岗位和流程重组。

## Claude Blog

### Introducing Claude Ship

- 日期：2026-11-23
- 链接：[Introducing Claude Ship](https://claude.com/resources/articles/introducing-claude-ship)
- 摘要：Claude Ship 推出 beta，将已正式可用的 Code Review 与测试中的 PR Steward、Claude Approvals 组合起来，处理审查、CI 失败、冲突和审批。团队通过仓库策略决定哪些变更可由 Claude 批准。
- 关注点：面向使用 GitHub 的 Team 和 Enterprise 团队；官方建议先观察审批策略。当前不支持启用零数据保留、HIPAA 配置或客户管理加密密钥的组织。

### The enterprise guide to securing coding agents

- 日期：2026-11-23
- 链接：[The enterprise guide to securing coding agents](https://claude.com/resources/articles/enterprise-guide-to-securing-coding-agents)
- 摘要：这份指南讨论企业扩大 Claude Code 使用时如何识别风险，并通过权限检查、隔离环境、外部动作检查和集中策略限制提示注入及权限滥用的影响。
- 关注点：安全和技术负责人可据此检查代理的执行边界、策略强制执行能力及事后审计能力。

### Zero data retention with Enterprise Frontier Safeguards is now in beta

- 日期：2026-11-23
- 链接：[Zero data retention with Enterprise Frontier Safeguards is now in beta](https://claude.com/resources/articles/zero-data-retention-with-enterprise-frontier-safeguards)
- 摘要：Enterprise Frontier Safeguards 开放公开 beta，在兼容零数据保留的同时提供跨请求的自动安全监测。系统分析存放在客户控制基础设施中的数据，以识别单次请求检查难以发现的滥用模式。
- 关注点：企业可重点评估日志保管与滥用检测如何分工，以及这种方式是否适合自身的数据控制要求。

### KPMG’s Todd Lohr：客户敏感数据场景下的 AI 应用

- 日期：2026-11-23
- 链接：[KPMG’s Todd Lohr：客户敏感数据场景下的 AI 应用](https://claude.com/resources/articles/kpmg-todd-lohr-on-ai-when-your-data-is-also-your-clients-data)
- 摘要：KPMG 的 Todd Lohr 介绍将 Claude 融入税务平台和专业服务的实践，并讨论 EFS 如何与其 Trusted AI 流程结合。客户数据留在受控基础设施中，是其采用前沿模型的重要条件。
- 关注点：这篇访谈提供了专业服务企业协调模型能力、数据保管和人工监督的具体视角；相关收益属于受访者的实践判断。
