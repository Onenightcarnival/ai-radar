# arXiv 论文雷达 2026-08-27

## 总评

当天共收录 409 篇论文，精读 50 篇；最密集的主题是智能体安全、长时程执行与评测，三篇必读分别落在上下文权限提升、TEE 权重保护和低成本小模型预训练。安全研究正从提示词攻防转向来源追踪、参数级授权、跨轮状态和真实物理后果，实验也越来越强调执行日志、隐藏状态与确定性验证，而不是采信模型自述。系统方向同时在压缩训练、推理、检索和评测成本，但不少亮眼数字依赖合成环境、特定硬件或额外调用预算，外推到生产仍需谨慎。

**方向：**
- 智能体安全开始围绕上下文重建后的权限变化、工具输出来源和跨查询记忆建立执行层控制，而不再只靠模型拒绝或提示注入检测。
- Agent 评测正从单步工具调用扩展到真实工作流、持续运行、物理过程和复杂交付物，并用日志、规则评分器或独立轨迹核验结果。
- 科研与编码智能体普遍采用多角色、共享状态、失败记忆和闭环实验，但收益往往同时混入更多调用、重试、筛选和人工介入。
- 低成本系统优化覆盖消费级 GPU 预训练、机密计算、KV 缓存、视频预训练、表格压缩和流式索引，重点逐渐转向真实硬件边界与端到端成本。
- 安全与隐私研究越来越重视表面指标掩盖的残余风险，包括低成功率后门、局部合成数据泄露、实验能运行但不忠实，以及授权操作被护栏误拒绝。
- 结构化接口重新成为 Agent 工程重点，JSON 状态、语义动作、计划 DSL、SQL 编排和类型系统被用来缩短轨迹并提供可检查的约束。

**跟踪：**
- 需要继续验证来源追踪、信息流控制和非衰减风险状态在多轮、多工具、持久记忆与复杂控制流下是否仍能保持低攻击成功率和可接受的误拒绝率。
- 科研智能体的核心缺口仍是实验忠实度，合同、AST 检查和日志核验能否识别规模缩减、方法替换和结论口径漂移值得长期跟踪。
- 多智能体和自我改进系统应补充等算力、等调用次数和独立测试集对照，分清协调机制、同题重跑与额外计算各自贡献。
- 硬件在环、机器人和工业控制结果需要跨设备、跨场景和更真实观测条件复验，避免把小规模成功率直接解释为现实攻击或部署能力。
- 合成基准与 LLM 评审仍可能引入生成器偏差、错误标准答案和评分迎合，后续应增加人工复核、规则判定及跨基准稳定性分析。
- 低成本训练、机密计算和缓存压缩方案还需公布完整设备、工程、人力与能耗账本，并验证二次计算、通信和维护成本是否抵消节省。
