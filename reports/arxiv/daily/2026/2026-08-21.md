# arXiv 论文雷达 2026-08-21

## 总评

今天共收录 159 篇，精读 50 篇，其中 4 篇列为必读、40 篇值得读；高质量工作集中在智能体安全与可审计执行、机器人评测、密码分析和大规模系统实验。多篇论文不再只比最终准确率，而是检查授权、证据、状态、轨迹和部署对象能否前后一致，这比再加一层提示词防护更接近真实系统问题。与此同时，不少亮眼结果依赖固定攻击集、合成任务、强提供商假设或内部生产环境，方法有启发，结论边界仍需收紧。

**方向：**
- 智能体安全正在从单次提示过滤转向覆盖授权、参数来源、副作用提交、结果核验、重试与恢复的完整状态机。
- 提示注入和记忆投毒研究开始面对自适应攻击、普通错误陈述和跨调用重试，单靠内容筛查或来源降权越来越站不住脚。
- 软件智能体评测逐步从最终是否修好，转向检查证据链、执行轨迹、跨会话记忆卫生、规格契约和部署制品绑定。
- 机器人方向更重视评测定义是否可信，示范遗忘、价值规划、双臂硬约束和触觉攻击都在区分表面成功与真正保证。
- 密码与隐私系统一边追求十亿级密文检索等工程规模，一边重新核查泄漏、存储、客户端参与和安全归约是否匹配宣传。
- Netflix 的长期随机实验和商品语义 ID 工作显示，推荐改进更可能把流量从头部推向中腰部，而不是自动扶起最冷门内容。
- 多向量检索、加法 FFT、凸集图搜索和几何双团覆盖等工作继续用明确的表示或复杂度界解释工程方法为何有效。
- 多篇系统论文采用 LLM 负责解释和候选生成、确定性程序负责路由与执行、验证器负责拒绝不充分结果的混合架构。

**跟踪：**
- 智能体防御能否在攻击者知道监控规则、能够跨轮改写目标并操纵工具返回值时仍保持低攻击成功率。
- 授权与副作用状态机在缺少幂等键、未执行证明或原子接口的真实支付和通信服务上如何落地。
- 自然语言工作流和神经形式化验证何时能把正确性覆盖到原始代码、库语义和运行环境，而不只覆盖 LLM 翻译后的模型。
- FHE 近邻检索能否显著压低数十 TB 密文存储和交互式路由成本，同时减少访问模式泄漏。
- 机器人遗忘、触觉攻击和学习规划器的结论能否在更多硬件、闭环任务和自适应对手下复现。
- 代码智能体基准能否补上完整召回率、真实回归风险、环境可复现性和多次运行方差，而不是只报告告警下降或单次通过。
- 来源可信度、长期记忆和时间有效性是否能在保留不可信渠道中真实证据的同时，压住无指令、外形正常的错误信息。
- 生产级推荐与搜索实验能否拆分语义 ID、模型升级、界面变化和供给过滤各自带来的增益。
