# arXiv 论文雷达 2026-08-25

## 总评

当天覆盖 367 篇论文，精读 50 篇，其中 2 篇必读、46 篇值得读；最集中的问题是 Agent 接入工具、网页、记忆和企业系统后，怎样限制越权动作、隐私泄露和外部输入污染。评测也在从最终答案转向执行过程，开始逐步核查工具调用、证据来源、代码语义、任务状态、资源占用和完整交付物。多数结果仍建立在合成数据、静态截图、自动裁判或受控环境上，论文给出的高分与真实部署能力之间普遍还有一段距离。

**方向：**
- Agent 安全边界继续前移到工具执行之前，单步拦截、参数最小化、指令来源定位、工具所有权和生命周期管理成为共同抓手。
- 基准不再只问结果对不对，而是检查长期记忆能否自然融入对话、科研产物是否完整一致、论文代码是否忠实实现要求、引用错误在哪个代理环节产生。
- 可验证机制明显增多，Lean 证明、差分训练核对、证据图、可复现输入子集和认证数据结构都在把模型输出变成可审计对象。
- Agent 外壳正在成为独立优化对象，工具 schema、确定性技能、任务状态、完成检查器、上下文压缩和升级策略都被纳入搜索或训练闭环。
- 系统论文更重视实际资源账本，KV-cache 是否真的释放显存、批量推测解码是否仍有收益、GPU 查询内核是否胜过强编译基线都开始接受端到端核查。
- 安全关键评测开始按后果而非表面语义计分，空管指令、胸片上下文和 GUI 操作都把高风险遗漏、错误诱导与普通格式偏差分开处理。

**跟踪：**
- 继续跟踪单步守卫和提示注入防御在自适应攻击、真实工具链与长轨迹中的漏拦截率和误杀率，而不是只看合成危险样本。
- 需要验证 Direct QA、静态截图和局部工具调用分数能否预测长期对话、浏览器操作和企业流程中的端到端成功率。
- 大量工作依赖 LLM 裁判、自动标签或蒸馏标签，判分稳定性、标签偏差和模型同源性仍可能放大结论。
- 凡是声称压缩、加速或省成本的方法，都应同时报告物理显存、端到端延迟、额外模型调用和失败回退后的净收益。
- 形式化证书和可认证鲁棒性需要明确覆盖范围，尤其要区分形式化定义成立、几何分离假设成立与真实系统安全之间的差别。
- 大型开放数据集和真实来电、医疗、企业数据实验仍要持续审计授权边界、可获取性、采样偏差和身份变量混杂。
- 工具创建、外壳搜索和递归记忆更新是否真正优于人工修补，需要隐藏任务、多随机种子和跨环境复现实验来确认。
