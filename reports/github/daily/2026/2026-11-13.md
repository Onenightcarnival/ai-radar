## 按主题归类的观察

- **AI / Agent 与安全：** 技能集合、安全扫描和行为评测分别回答“怎么做”“是否危险”“是否有效”。接入时应保存同一任务的对照结果，避免只凭扫描通过就认定技能有用。
- **前端：** 编码规范与设计系统可以一起试用，但需要分别验收语义结构、交互和视觉表现。已有组件库的团队先比较适配成本，再决定是否迁移。
- **数据与开发工具：** 数据库客户端提供了独立于 Agent 的工具观察样本。连接稳定性、大结果集响应和日常查询体验，比单日 stars 更能决定留用。
- **基础设施与执行：** 浏览器自动化、设备控制和自托管交付都涉及外部状态变化。测试应覆盖取消、重试和恢复，保留足够记录定位重复执行。

## 可行动建议

- **开发者：** 用一个现有 Web 页面对照试用前端指导与工程技能，记录生成代码通过检查的比例和手工修改时间。
- **技术负责人：** 为技能建立小型验收集，分别衡量安全风险、任务成功率和执行成本；交付工具先在测试仓库验证恢复流程。
- **产品 / 投资观察者：** 关注安全扫描、技能评测和前端指导是否进入团队的第二次真实任务，访谈使用频率、维护负担及付费意愿，不以单日增星推算采用规模。
