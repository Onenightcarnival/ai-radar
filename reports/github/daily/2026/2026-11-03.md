## 按主题归类的观察

- **AI / Agent 与开发工具：** 远程控制、桌面操作和记忆分别影响接管、执行和恢复。试点应明确要减少哪一类人工操作，避免同时更换多套工具后无法归因。
- **安全与数据：** AiSOC 与 Scrapling 都依赖可追溯输入。调查结论要能返回原始告警，采集结果要能返回原页面；错误输入的识别与修复应纳入验收。
- **基础设施：** FreeToken 与 Colibri 提供不同的本地运行尝试。硬件条件会直接影响结果，尤其需要区分冷启动、磁盘读取与模型计算耗时。
- **前端与输入体验：** 历史地图和语音输入都有可直接观察的交互成本。前者看时间与空间联动是否清楚，后者看纠错后是否仍比键盘输入省时。

## 可行动建议

- **开发者：** 选一个每天重复的桌面任务，分别记录手动执行和 Agent Desktop 执行的耗时、失败次数与接管步骤；已有远程控制试点则优先补齐取消和恢复测试。
- **技术负责人：** 用同一台机器和固定模型配置对照本地推理工具，设定可接受的首字延迟、内存上限与输出质量，再决定是否扩大试点。
- **产品 / 投资观察者：** 跟进 Agent 控制与记忆工具的重复使用情况，关注用户是否完成第二次、第三次真实任务，以及团队是否愿意承担配置与维护成本。
