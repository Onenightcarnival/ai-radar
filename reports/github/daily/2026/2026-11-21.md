## 按主题归类的观察

- **AI / Agent 与开发工具：** 命令行入口和交付工作流解决不同层面的问题。前者需要明确的操作结果，后者需要可追踪的任务状态；组合试用时，应保留每次操作、审批和重试记录。
- **前端与设计：** Stitch 技能库把设计工具接入 Agent 工作流。评估重点可以从首次生成效果转向第二轮修改：布局是否稳定、产物是否便于继续编辑、已有交互是否保留。
- **数据与基础设施：** Firecrawl、dbx 和 NGINX 分别涉及外部内容、数据库操作与流量服务。试点可分别设置过期内容、查询超时和高并发请求，检查失败是否能被发现和恢复。
- **安全与模型学习：** 安全技能要以可复现漏洞和修复验证验收；小模型训练项目适合学习训练过程。热度不能替代漏洞证据，也不能替代固定测试集上的模型评估。

## 可行动建议

- **开发者：** 选一个重复的软件操作任务试用 CLI 接口，保留输入、返回值和产物；主动中断一次，检查重试是否生成重复结果。
- **技术负责人：** 为 Agent 交付流程安排一个小型修复试点，明确审批节点、重试边界与回滚条件；安全和数据工具继续使用已有对照集，避免每次换样例后无法比较。
- **产品 / 投资观察者：** 跟踪操作入口和交付工具是否带来重复使用，重点询问每周完成任务数、失败恢复耗时和维护负担；将试用兴趣与实际留存分开记录。
