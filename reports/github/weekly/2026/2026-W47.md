# GitHub 热点周报 2026-W47

本期回顾 2026-11-09 至 2026-11-15，关注 Agent 工程质量、前端指导与执行工具的热度分化。

## 本周趋势概览

- **技能评测与安全验证反复出现。** SkillSpector、SkillEvaluator 和 Codex Security 各在两份日报重点表中出现，工程技能集合连续三期出现；关注点从提供技能延伸到检查技能是否安全、是否有效。
- **前端规范出现短期爆发。** Astryx 在三份日报出现，Modern Web Guidance 连续三期出现；后者日增从 739 升至 1,925，再降至 1,231，值得跟踪进入实际项目后的留用情况。
- **执行工具保持关注，但上期高增长项目普遍降速。** T3 Code、Agent Desktop 和 OpenMausBot 周榜增量分别较上期减少约 40%、66% 和 28%；Agent Browser 仍三次进入日报重点表，浏览器执行是本周持续出现的具体场景。
- **数据工具呈现分化。** Auto Ontology 周增明显回落，Omnigraph 周末日增增加；语义查询与图数据版本管理都值得试用，但不能据此推断整个数据库方向升温。

## 本周高频主题归类

- **AI / Agent 与开发工具：** 工程技能三次出现，技能参考与上下文压缩各两次出现；复用流程和保存约束仍是长任务中的共同问题。
- **安全：** 技能扫描、行为评测、漏洞修复均重复出现，周末另有 PyRIT 和代码审查工具。安装前扫描、运行效果评测和代码漏洞验证应分别验收。
- **前端：** Astryx 与 Web 指导各三次出现，周末补充 DevTools MCP 和计划批注工具，形成从规范、组件到浏览器调试与人工反馈的一组观察对象。
- **数据与基础设施：** Omnigraph、Dbdelve 和 NVKE 各两次出现，分别涉及图数据版本、数据库操作和 GPU 集群管理；监控与网络连接工具为周末补充样本。
- **本地创作：** Concat 连续两期出现，另有 VoiceStudio 和 FFmpeg 技能，适合围绕可重复编辑、导出质量和中断恢复进行验证。

## 与上一期周报相比值得注意的方向变化

- **从操作环境扩展到工程验收。** W46 强调远程控制、桌面操作和工作目录隔离；本期技能扫描、效果评测、漏洞修复与人工反馈更加集中，值得把验收成本纳入工具选择。
- **前端关注对象转向具体规范与组件。** 上期 Impeccable 周增回落，本期 Astryx 周增 13,501、Modern Web Guidance 为 5,692；这说明观察样本发生变化，尚不能推出设计技能被替代。
- **语义数据与执行工具的爆发均有降速。** Auto Ontology 周增 9,327→2,878，Agent Desktop 13,712→4,719；下一阶段应重点看是否继续解决真实任务，而非延长峰值增长预期。

## 适合下周继续观察的项目和主题

- Astryx、Modern Web Guidance：观察冲高后的增量与维护情况，用同一页面对比可访问性、兼容性和手工修正量。
- SkillSpector、SkillEvaluator、Codex Security：跟踪安全检查与行为评测能否进入第二次真实任务，分别记录误报、成功率与复核成本。
- Agent Browser、OpenMausBot、T3 Code：保留长任务的取消、恢复和重复执行记录，判断执行工具是否降低人工接管频率。
- Omnigraph、Auto Ontology：分别验证版本隔离与语义查询正确性，关注数据修改后的结果一致性。

## 可行动建议

- **开发者：** 用一个已有页面缺陷串起规范指导、浏览器调试和人工反馈；保留原流程对照，记录完成时间与返工次数。
- **技术负责人：** 为技能建立正常、危险和未见任务三类样本；为执行环境增加取消、重试和恢复检查，通过后再扩大接入。
- **产品 / 投资观察者：** 访谈第二次使用者，区分尝鲜、个人留用与团队采用；前端工具看迁移成本，安全工具看复核工时，数据工具看实际负载。
